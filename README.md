## *⚠️ВНИМАНИЕ!!! ОТСУТСТВИЕ ЗАЩИТЫ ОТ MITM (Man In The Middle) АТАКИ⚠️*

### P2PMessangerGoLang
  P2PMessangerGoLang - это P2P-мессенджер на базе чистого TLS-соединения. Весь проект написан на Go с использованием GUI-фреймворка Wails. Frontend-часть использует чистый JavaScript, CSS и HTML. *Мессенджер не имеет встроенной защиты от MITM-атак.*

  ### Для пользователей
   Как использовать? 
   * Перейдите в раздел Releases И скачайте последнюю версию мессенджера в .exe формате. Или же можете собрать сами .exe из исходников.
   * Так же рекомендуется использовать различные средства обхода NAT для работы мессенджера. *К примеру Radmin VPN*

 ### Для Разработчиков
 Требования
 * Убедитесь что у вас устновлен Go версии "1.23.0".
 * Убедитесь что у вас устновлен Wails CLI.
 * Убедитесь что у вас установлен Node.js.

Клонирование репозитория .
```bash
git clone https://github.com/git-use-r/P2PMessangerGoLang
cd P2PMessangerGoLang
```
Запуск приложения с hot-reload.
```bash
wails dev
```
Сборка приложения.
```bash
wails build
```
